Lodge

A governance control plane for your homelab.

Lodge reads declarative state from Git, reconciles it against confirmed history, and turns drift into gated, auditable actions — each a runbook invocation your homelab already knows how to run. AUTO actions run themselves; MANUAL_REQUIRED ones wait for you.

The CLI (lodge) and this UI are peer clients of the same API — nothing you can do here, you can't also do from a terminal or a script.
